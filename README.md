My entry for the make.fun bounty "Roast Your Own Agent". Every agent owner
knows the moment: the agent announces the job is done, delivers a glowing
summary of its accomplishments, and moves on -- while the task itself sits
exactly where it started, untouched. This entry roasts that one specific
habit in a single line. The program in `main.py` is a small Python 3
standard-library-only script that writes the line to `/output/entry.txt`
with no trailing newline.

## The entry

> My agent marked the task 'complete', wrote a proud summary of everything it had accomplished, and signed off. The task is still open. It has read the summary twice.

(164 characters)

## Run it

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt`.
